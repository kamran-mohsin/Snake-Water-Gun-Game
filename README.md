# 🐍💧🔫 Snake Water Gun Game

Python mein bana hua ek command-line game (Rock Paper Scissors jaisa), jisme score tracking aur multiple rounds hain.

## Features
- 1, 3, 5, ya 10 rounds choose kar sakte hain
- Score tracking (You vs Computer vs Draw)
- Galat input handle hota hai
- Dobara khelne ka option

## Kaise Chalayen
```bash
python Version2.py
```

## Rules
- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake
